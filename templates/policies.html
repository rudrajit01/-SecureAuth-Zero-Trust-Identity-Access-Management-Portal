Sign-in Decision Flow

  1. Verify password (bcrypt salted hash). Failed attempts increment the failure counter; reaching {{ values.max_failed_attempts }} failures triggers an account lockout for {{ values.lockout_minutes }} min.
  2. Risk score evaluation (0-100):
    • Unrecognized device: +30
    • Unrecognized location: +25
    • Foreign country (outside India): +20
    • Unusual hours ({{ values.unusual_hour_start }}:00 to {{ values.unusual_hour_end }}:00): +20
    • Recent failed sign-in attempts: +15
  3. Risk ≥ {{ values.block_risk_threshold }} → HIGH → {{ 'BLOCK'|safe if values.block_high_risk=='1' else 'MFA required' }}
  4. Risk ≥ {{ values.mfa_risk_threshold }} → MEDIUM → MFA required
  5. MFA not registered → MFA enrollment enforced
  6. Admin/Manager → {{ 'Mandatory MFA'|safe if values.always_mfa_privileged=='1' else 'standard rules' }}
  7. Low risk + trusted device → Allow (seamless sign-in)
All policy modifications are logged in the audit trail with high severity for compliance and governance accountability.
